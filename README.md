# FitForge — Fitness Web App

Local dev (requires Node 18+):

```bash
npm install
npm run dev
```

Features:
- Workout plans (sample templates)
- Exercise library with images
- Calorie calculator (Mifflin-St Jeor) and macro guidance
- Bold orange & black design
